# Material y códigos de clase — DAM

Repositorio de material académico utilizado durante el ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)** en la Universidad Europea.

Incluye tanto **ejercicios y prácticas propias** como **material docente, ejemplos y código facilitado por profesores** como apoyo durante las clases. El repositorio se conserva con finalidad formativa y como referencia del aprendizaje realizado durante los dos cursos del ciclo.

## Contenido

El material está organizado principalmente por asignaturas:

- **Acceso a Datos**
- **Desarrollo de Interfaces**
- **Lenguajes de Marcas**
- **Programación Java**
- **Programación Multimedia**
- **Python**
- **Servicios y Procesos**

## Nota sobre la autoría

No todo el contenido de este repositorio ha sido desarrollado íntegramente por mí. Parte del código corresponde a ejemplos y materiales docentes proporcionados por los profesores para facilitar el seguimiento de las clases.

Mis proyectos y ejercicios propios se muestran de forma separada en otros repositorios de este perfil cuando tienen entidad suficiente para formar parte del portfolio.
